## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload the contents of this ZIP (not the ZIP file itself) to the repository root.
3. Commit and push the files.
4. In the repository, open **Settings → Pages**.
5. Choose **Deploy from a branch**, select your main branch and `/(root)`, then save.
6. Wait for GitHub Pages to publish the site.

No build step, Node.js, backend, or database is required.

## Before publishing
Review the screenshots for any information you do not want public. The screenshots are presented as evidence from the TryHackMe training environment. Replace or remove any evidence that you do not want included in a public portfolio.
